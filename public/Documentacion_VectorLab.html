Módulo: Gestión de Inventario

Documentación oficial de procesos, arquitectura de información y experiencia de usuario.

Versión 1.0 | Sistema VectorLab

El módulo de Gestión de Inventario de VectorLab ha sido diseñado para ofrecer una experiencia operativa fluida, centralizada y de alta velocidad. Entendiendo que el control de existencias es el pilar de la rentabilidad, este módulo minimiza los clics necesarios para realizar tareas rutinarias (como actualizar stock o dar de alta mercancía) e incorpora un sistema reactivo que actualiza la información en tiempo real sin recargar la página.

Visión del Módulo

El objetivo principal es permitir a los administradores y operadores logísticos manejar miles de referencias de productos con precisión matemática, manteniendo siempre la trazabilidad de los proveedores, categorías y alertando proactivamente sobre el desabasto (Stock Mínimo).

1. Búsqueda y Navegación Inteligente

El corazón operativo del inventario es su capacidad de encontrar información al instante. La tabla principal no requiere botones de "Buscar". Todo el filtrado es asíncrono y en tiempo real. Esto permite al usuario tomar decisiones rápidas mientras habla con un cliente o revisa un estante físico.

Flujo del Usuario (Búsquedas)

  • Búsqueda Global: Al teclear en la barra superior, el sistema busca coincidencias instantáneas tanto en el Nombre del Producto como en su Código de barras o SKU.
  • Filtro por Proveedor: Un menú desplegable permite aislar visualmente toda la mercancía suministrada por una marca o empresa específica, ideal para realizar pedidos de reabastecimiento.
  • Alerta de Faltantes: Un interruptor dedicado filtra la base de datos para mostrar únicamente aquellos productos cuyo stock actual es menor o igual a su stock mínimo de seguridad.

2. Ciclo de Vida del Producto

La creación y modificación de un producto en VectorLab está estructurada en un formulario inteligente de una sola pantalla, dividido ergonómicamente en áreas de interés. El sistema está preparado para que, si el usuario nota que le falta registrar la categoría o al proveedor de la mercancía, pueda darlos de alta desde ahí mismo sin perder los datos que ya escribió.

Estructura del Formulario

  • Información Básica: Nombre comercial, Código identificador único, asignación de Categoría y asignación de Proveedor.
  • Estructura de Precios: Costo de adquisición, Precio de Venta al público y Precio de Mayoreo. (El sistema utiliza estos datos en otros módulos para calcular el margen de utilidad).
  • Control de Stock: Se define el stock mínimo (para activar alertas) y el método preferido de ingreso de la mercancía (Por unidades sueltas, por paquetes o por cajas), lo cual agiliza futuros surtidos.

3. Surtido y Actualización de Stock (Logística)

Una de las funcionalidades más potentes del sistema es su calculadora logística de ingresos. Cuando llega mercancía nueva al almacén, el usuario no necesita hacer cálculos manuales. El módulo deduce la cantidad de piezas totales basándose en cómo llega empaquetada la mercancía.

Métodos de Ingreso Automatizados

Al hacer clic en el botón de ingreso de un producto, el sistema presenta tres escenarios matemáticos según la configuración del producto:

  • Unidades: Para mercancía suelta. Si llegan 50 piezas, el usuario teclea 50 y el sistema suma 50.
  • Paquetes: Para mercancía agrupada. El usuario indica cuántos paquetes llegaron y cuántas piezas tiene cada paquete. El sistema hace la multiplicación.
  • Cajas Master: Para compras por volumen. El usuario indica número de cajas, paquetes dentro de la caja, y piezas dentro del paquete.

En tiempo real, mientras el usuario escribe, el sistema le muestra exactamente cuántas piezas totales están entrando y cuál será el Nuevo Stock Final. Esto reduce los errores humanos casi a cero.

4. Gestor Unificado de Categorías

Anteriormente fragmentado, el Gestor de Categorías ahora es un centro de comando unificado. Permite a los administradores del inventario mantener el catálogo de clasificaciones totalmente limpio y organizado desde una sola pantalla, con total soporte para atajos de teclado para operaciones masivas.

Características del Gestor

  • Alta Inline: Un campo de texto fijado en la parte superior permite crear categorías escribiendo el nombre y presionando "Enter", sin abrir pantallas adicionales.
  • Edición y Eliminación: Cada categoría en la lista tiene botones de acceso rápido para renombrarlas o borrarlas. Si se elimina una categoría, el sistema es lo suficientemente robusto para proteger los productos: simplemente los reasigna a la categoría general sin eliminar mercancía.

5. Generación de Reportes y PDF

El módulo cuenta con un sistema de exportación diseñado para la comunicación empresarial directa. Ya no es necesario descargar el inventario para enviarlo como adjunto manualmente. VectorLab permite enviar el reporte oficial directamente a un teléfono celular o a una dirección de correo institucional.

Flujo de Exportación

El usuario tiene el poder de decidir si desea exportar absolutamente todo el inventario de la tienda, o si desea usar las casillas de verificación (checkboxes) para armar un catálogo personalizado de 5 o 10 artículos específicos para enviárselo a un cliente como cotización o a un proveedor como orden de compra.
